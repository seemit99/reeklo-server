## 이번에 반영한 주요 기능

### 광장 경험

- 로그인 후 광장 선택 화면을 거치지 않고 추천 광장으로 바로 배정한다.
- 광장과 방을 사용자 관점에서 하나의 광장 개념으로 정리했다.
- 기본 운영 광장, 개인 광장, 사용자가 만든 광장의 생명주기를 구분했다.
- 사용자가 만든 광장은 마지막 사용자가 나가면 물리적으로 삭제하지 않고 `use_yn='N'`으로 비활성화한다.
- 카테고리, 검색어, 태그로 광장을 찾을 수 있다.
- 신규 광장에 비밀방 여부와 입장 비밀번호를 설정할 수 있다.
- 광장 변경 중 단순 남색 화면 대신 상세 로딩 화면을 표시한다.

### 공통 UI

- 광장 상단을 `REEKLO / 현재 광장 / 접속 인원 / 설정` 한 줄 구조로 정리했다.
- 캐릭터, 마켓, 길드, 설정은 광장을 벗어나지 않는 팝업 패널로 표시한다.
- 광장 생성 폼도 중앙 팝업으로 표시한다.
- 말풍선, 이모티콘 잘림, 팝업 스크롤과 크기를 정리했다.
- 로그인 화면의 장식 아이콘과 불필요한 문구를 제거하고 폰트를 통일했다.

### 데이터 정책과 채팅

- 업무 데이터는 물리적으로 삭제하지 않고 `use_yn`으로 활성·비활성 상태를 관리한다.
- `chat_messages`에 광장·개인·길드 채팅을 저장할 수 있도록 서버와 스키마를 준비했다.
- 메시지 저장은 신고 처리와 운영 감사에 활용한다.
- 비밀번호, 광장 입장 비밀번호, 복구 답변 같은 인증 정보 원문은 저장하거나 관리자 화면에 노출하지 않는다.

### 회원가입과 계정 복구

- 회원가입에 개인정보 수집·이용 필수 동의를 추가했다.
- 회원가입과 비밀번호 재설정에 비밀번호 확인 입력을 추가했다.
- 별도 이메일 발송 서비스 없이 단일 복구 질문과 답변으로 비밀번호를 재설정할 수 있다.
- 복구 답변은 bcrypt 해시로만 저장한다.
- 답변 확인에 5회 실패하면 15분 동안 재시도를 잠근다.
- 비밀번호 재설정 시 기존 로그인 세션을 무효화한다.

### 관리자 기능

- `ADMIN` 역할과 `use_yn`을 서버 권한 검사에 사용한다.
- 일반 사용자는 관리자 라우트와 API에 접근할 수 없다.
- 관리자 대시보드에서 사용자, 광장, 방, 채팅 메시지, 신고, 길드, 복구 질문, 관리자 감사 로그를 읽기 전용으로 조회할 수 있다.
- 조회 가능한 테이블은 서버 허용 목록으로 제한한다.
- 관리자 조회 행위는 `admin_audit_logs`에 기록한다.
- 비밀번호와 복구 답변 해시는 관리자 API 응답에서 제외한다.
- 별도 관리자 계정을 만들지 않고 기존 `jwpark429@naver.com` 계정에 `ADMIN` 역할을 부여했다.
- 기존 계정의 비밀번호는 변경하지 않으며 Git이나 문서에 기록하지 않는다.
